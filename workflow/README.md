本包是资料链路演示，不是可直接生产的设计。先用生活化原话描述，再逐项明确确认用途、供电、查看方式、演示路线、测量对象及温度目标；不声称通用自然语言理解；单位先统一，已识别原话温区/误差/查看方式/测量对象/节点电压必须与表单一致。便携不推电池，型号/电压/精度不暗填。控制/电池/C3或DHT替代等当前不支持时明确告知，不自动改成S3+BME。

固定旧9记录的公开审核快照＋LIB02H条件公开快照分别保留原基线，共同归于本项目版本，不混作实时13源库，不读取原PDF或执行SQL。条件Typ参考不是保证，端点未比较/脚注/测量对象差异仍保留。湿度目标可记录，但现有规则只覆盖温度相关资料，湿度没有因此通过。单点温度可能被旧通用审核要求继续澄清，条件对照可单独返回受限结果，二者不自动合并成通过。
