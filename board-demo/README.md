# 参考板网页：客户演示版

参考演示已公开，本目录是独立客户交付副本：更新了旧候选标签和说明，并重新绑定版本/哈希；图、工程ZIP、来源包和失败摘要没有改字节。原封存与线上19文件未覆盖。

**PCB检查失败223项，不能制板。** 间距8、同封装24、过孔85、GND连接105、网表不一致1；另有6条导入符号编号自动修复、铺铜未填提示。原因待定位，不能把GND问题全归因未填铜。

在线版可直接浏览；使用完整客户包时从包根运行npm start，打开页面中的“互动网页”。单独下载本前端目录时需要自己的只读HTTP静态服务，不直接双击index.html。本页真实调用浏览器规则、同源固定JSON与资产，SHA匹配才载入参考图/工程；不是服务器实时画板，也不实时查询后面的PostgreSQL资料库。需要Node24（本包实测）和现代浏览器，无npm外部依赖。

明确接受S3+BME280、USB-C5V、串口、8MB无PSRAM、整块参考原样、误差仅作待验证目标；OLED、N16R8、裁剪/改板、必须保证精度等会阻断。修改需求清旧图和审核，不会自动修改参考电路。
