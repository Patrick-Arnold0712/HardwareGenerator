## 一、这份东西是什么

把一句话硬件需求，变成可在**嘉立创 EDA 专业版 V4.1+** 打开并验证的 `.eprj3` 工程包。

```text
说想法 → 澄清需求 → 选方案 → 真实生成 .eprj3 → 格式校验 → 客户端回读验证 → 下载 ZIP
```

**这是链路验证版本，不是可直接生产的设计。**

## 二、能做什么

| 能力 | 状态 |
|---|---|
| 五步网页向导（面向不懂硬件的用户） | ✅ 可用 |
| 生成 `.eprj3` 工程（原理图 + PCB + 走线） | ✅ 可用，2 个模板 |
| 格式校验（上游 `validate.js`） | ✅ 0 errors, 0 warning(s) |
| 嘉立创 EDA V4 客户端真实回读 | ✅ 已验证 |
| BOM / manifest / 验证证据 | ✅ 可用 |
| ZIP 打包下载 | ✅ 可用 |

## 三、不能做什么（重要）

以下**明确不在当前交付范围**，对外沟通请勿承诺：

- ❌ 不支持任意电路，只有 2 个固定模板
- ❌ 不生成 Gerber / CPL / 钻孔文件
- ❌ 不含外壳 CAD（STEP / STL / 3MF）
- ❌ 不含固件源码或二进制
- ❌ 未做 DRC / DFM
- ❌ 未映射真实 LCSC 料号与库存
- ❌ 不承诺电气正确性与量产可制造性

系统内部用 `deliveryStatus` 标记交付等级，**自动化最高只能到 `engineering_preview`（工程预览）**，代码层面禁止越级声明。

## 四、怎么运行

需要 **Node.js 18+**，无需安装任何 npm 依赖。

```powershell
git clone https://github.com/Patrick-Arnold0712/HardwareGenerator.git
cd HardwareGenerator
npm test          # 21 项本地测试 + 121 项上游测试
npm run wizard    # 启动向导
```

浏览器打开 **http://127.0.0.1:7788**

> ⚠️ 不要直接双击 `src/wizard/index.html`。页面需要本地服务，直接打开会提示「还没连上服务」。

## 七、已知问题

**客户端验收报 `Cannot find module`**

如果终端里有 `ELECTRON_RUN_AS_NODE=1` 环境变量（部分 Electron 工具会注入），`lceda-pro.exe` 会被当成 Node 解释器执行。先执行：

```powershell
Remove-Item Env:ELECTRON_RUN_AS_NODE
```

再运行 `npm run verify:client`。
