## 普通用户怎么用

可一键选择“0～65℃”“-10～50℃”“0℃单点”或“环境温度”的例子，也可手动填写。

这是**你自己选择/填写的条件**，不是系统从一句自然语言自动推导温区。内部温度是芯片的读数，不能直接当成室内空气温度；“允许误差±0.5℃”是你的目标，不是已经获得的器件承诺。

点击核对后，先看保证精度UNKNOWN和端点提示，再看范围字段及完整四行Typ资料。没有隐藏NOT_COMPARED、不保证行或脚注7/8/9。Typ不是保证上限；含端点的区间不能只因为正温Typ数值在目标内就视为全部符合。工程仍NOT_RUN，design_approved=false，不批准选型或整板。
