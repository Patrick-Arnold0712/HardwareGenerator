# 温度计资料候选演示（公开静态版）

通过静态网站打开 `index.html` 使用；将本目录完整部署为网站根目录即可。已实测项目子路径；本轮未测试直接双击file://打开。无需Node服务、SQLite、账号或API密钥。脚本和样式均使用相对路径，支持GitHub Pages项目子路径。

1. 点“只说一句想法”并分析，会询问缺失条件。
2. 补充用途、电源、测温范围、误差和输出方式，再筛选资料。
3. 查看候选来源、UNKNOWN及缺口；底部展开的是**快照过滤描述**，不是SQLite执行日志。

排除/替换要求无法可靠理解时会要求重述最终需求，不会静默换器件。需求在当前浏览器计算，不上传、不持久保存；没有统计脚本、远程字体或第三方JS。访问网站本身仍会向网站托管方请求静态资源；点击来源链接会访问相应外部网站。

## 资料版本与边界

使用 `public-metadata-20261101-r1` 的9条白名单元数据快照。快照不会自动更新，不是实时SQLite查询。核心受限解析来自0.3，浏览器版仅做数组过滤与已登记参数比较。`search_terms`是保留原索引有限关键词命中的公开分类标签，不是完整原始记录。

找到资料不代表适配、选型批准或复用许可；UNKNOWN表示缺少可核查字段。显示器、控制器独立记录等仍有缺口。此演示不生成整板、PCB或制造文件，不证明测量准确性、硬件功能或生产可行性。
