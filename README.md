# 温度计：资料快照与受限审核

**公开版候选0.1，尚待独立审核和发布复核。** 本目录可完整部署到静态网站；不需要Node、SQLite、账号或API密钥。不要把“准备好了”当成已有可用的客户网址。

## 怎么用

打开网站，点击三个例子之一，再点击“找资料，看看哪里有问题”。也可直接填写最终需求。

你会分别看到：需求是否完整、哪些资料找到、每条参数满足/不满足/未知、是否超出本版范围，以及实际电路检查是否运行。还会列出排除、缺少记录、阻断理由和下一份需要补的证据。

只有明确要求“BME280裸芯片VDD直接接5V”时，才与旧快照登记的1.71—3.6V比较。普通USB-C系统5V不等于芯片VDD直接5V；稳压路径不清楚就UNKNOWN。身份或某个参数MATCH不是整机可行，工程检查没有真实证据就NOT_RUN。不生成电路、PCB或执行器控制方案，不批准选型。

## 与原始数据库版有什么不同

- 此版只在浏览器使用 **public-metadata-20261101-r1** 的固定9条公开元数据，数据不会自动更新，**不混用后来补充的器件事实**。
- 原本地运行版读SQLite并核对源文件；此版不连接数据库、不执行SQL、不检查原始metadata/PDF。展示的是数组操作、过滤参数和公开快照/记录哈希，**不是SQL日志或原文件证据**。
- 页面先核对固定快照内容指纹；不一致就停止，不能沿用旧审核结论。这只能发现当前固定包被更改，不证明第三方参数正确或证明原图纸已审阅。
- 需求只在当前浏览器计算，不上传、不持久化。没有统计服务、远程字体或外部JS；访问网站本身仍向托管方请求静态资源，点击官方来源链接会访问外部网站。
- 本版使用Web Crypto，需要支持该能力的现代浏览器，建议HTTPS；本机HTTP预览可测试。直接file://及全部设备尚未验证。

有限语法之外仍可能追问，不是通用自然语言审核。第三方许可unknown/none未变，见THIRD_PARTY_NOTICES.md；原PDF/图纸/第三方源码没有打包，也不被项目MIT重新授权。

## 发布边界

只发布本目录10个白名单文件：`.nojekyll`、`LICENSE`、`README.md`、`THIRD_PARTY_NOTICES.md`、`index.html`、`styles.css`、`snapshot.js`、`engine.js`、`audit.js`、`app.js`。不含本机证据、SQLite、客户文件、固件或vendor。部署前须完成EDA审核与管理的脱敏/哈希复核；不以此页面宣称D3–D5、PostgreSQL迁移或三份参考完整性完成。

## 易读文案候选 plain-r1

这一版只调整页面文字和详细依据的展开方式，没有更新引擎或资料快照。页面先显示“现在还不能确定”等易读提示；原状态代码、参数条件和来源保留在详细依据中。实际电路测试限制只指当前候选工程，不是否定其他历史实验。
