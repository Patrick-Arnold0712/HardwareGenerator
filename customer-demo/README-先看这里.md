# HardwareGenerator 客户演示交付包

## 先看结果
用浏览器打开“一键说明/客户入口.html”，可直接看图文；互动网页需本地服务。

安装Node.js24后，在这个包的根目录打开终端：
```text
npm test
npm start
```
不需要npm install。打开程序显示的本机网址。前端与图文不需要PG、SDK或付费AI。服务只绑定127.0.0.1，停止时按Ctrl+C。

## 包里有什么
- 前端：真实参考板原理图/PCB和工程下载，更新了旧候选说明。不是自动布线。
- 数据库：13条公开派生资料+1条来源事实关系、SQL、导入/verify源码、原10测试和PG实测范围摘要。不是原v5全量转储。
- 图文：7步真实操作和全部展示依赖。截图、原下载记录摄于发布前，历史标签不修图。
- 一键说明：入口、只读本地服务、校验和来源映射。

## 必须看见的问题
**PCB检查失败223项：间距8、同封装24、过孔85、GND连接105、网表不一致1。未修复，不能制板。** 另有6条符号编号自动修复和铺铜未填提示，原因待定位。温湿度精度、串口固件、整板和实物没有因此通过。
